# Web Assets

Brand files for the Foap Creative Intelligence header.

All artwork pixels come from the official Foap logo image supplied for
this project. Nothing here is redrawn or reinterpreted: the files below
are mechanical web preparations (trim margins, split the camera mark
from the wordmark at its natural gap, map the white background to
transparency, downscale for icons).

## Present

- `foap-logo.png` — full horizontal Foap lockup, transparent
  background, native resolution (crisp at 2x). Used top-left in the
  app header next to the "Creative Intelligence" product name.
- `foap-mark.png` — compact Foap camera mark cropped from the same
  official artwork, square-padded with transparency. Used for the
  Apple touch icon and small collapsed contexts.
- `favicon.png` — 64px downscale of the camera mark for the tab icon.
- `README.md` — this file.

## Dark mode

The header logo keeps its official teal on a white pill container in
dark mode (see `Index.html`), so the artwork itself is never altered
for theme readability.
